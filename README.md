# Jasmine Hou — Portfolio

A responsive, single-page portfolio built with semantic HTML, modern CSS, and lightweight vanilla JavaScript. It is intentionally dependency-free so GitHub Pages can serve it directly and updates stay simple.

## Local preview

Open `index.html` directly, or serve the folder with any static file server.

## Content

Project facts and links are based on the public repositories at [github.com/jasminehou07](https://github.com/jasminehou07). The narrative background is deliberately general so it can be replaced with a fuller biography or résumé later without changing the layout.
